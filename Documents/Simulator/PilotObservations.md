# 初次試騎觀察

## 2026-11-01 回報：較快時主觀上比較不暈

- 來源：開發者完成簡單試騎後的回饋：「我覺得速度快點反而比較不暈」。
- 性質：個別主觀觀察，尚非受控制的速度條件比較。
- 未記錄：對應的實際車速、路段、暴露時間、視覺條件、串流幀率、先後順序與量化不適評分。因此不能補成特定速度範圍或一般化結論。
- 本次保留原有預設速度，保留全域/各段速度上限參數與具名 JSON profile（此次簡化選單不提供速度編輯），方便下次比較；不把個別觀察直接寫成自動調速規則。

待查假設：目前模型在速度較高時會縮小最大轉向角；感受差異可能同時受到實際轉向幅度、反覆修正方向、路線或適應順序影響。這是依程式推論的可能干擾，尚未驗證原因。
